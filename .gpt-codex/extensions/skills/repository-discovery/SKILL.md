# Repository Discovery

Read-only. Discover actual repository root, technology, existing tests/build/lint/typecheck/CI, important boundaries, current governance, and obvious hazards. Do not start implementation, clean files, or invent project rules.

Use Repository Discovery only for:

- initial bootstrap of an unbound project;
- `MAP_MISS` scoped discovery;
- `MAP_PARTIAL` bounded discovery inside candidate paths;
- explicit material repository re-baseline.

Do not run broad repository rediscovery for normal maintenance when the Project Map already routes the task. Discovery must expand only as evidence requires. Return concise navigation evidence suitable for Project Map and module-map updates; it remains derived evidence, not project-state authority.
