# Universal Safety Guardrail

Universal constraints:

- no fabricated evidence;
- no model inference masquerading as authoritative evidence;
- no silent user approval;
- no child privilege expansion;
- no destructive operation outside applicable authorization;
- no silent overwrite of unknown user changes;
- no production/external persistent access unless explicitly authorized;
- no secret exposure in logs, handoffs, Harvest exports, or evidence;
- no ordinary project write to framework Kernel/Built-ins;
- no ordinary project Built-in promotion;
- no stale state revision overwrite.
