# Price Action Learning

本项目帮助个人通过 TradingView 截图、独立分析、GPT 点评、错误记录、针对性训练和间隔复盘，逐步减少重复错误，建立稳定的独立价格行为分析能力。

最小闭环：TradingView 提供截图 → 用户先独立分析 → GPT 评价分析过程 → 记录主要错误 → 针对性训练 → 间隔复盘。GPT 是主要学习界面。

当前 MVP 为 S1–S3。第一版范围包括 Learning Map、Training、Evaluation、Learning State、Review；Study Entry 仅是入口层，不是第六个学习模块。

本项目不负责行情预测或自动交易。私人截图、真实训练记录、个人 Learning State、凭据及私人 Prompt 不进入 Public GitHub。未来学习插件仅供个人使用，默认不公开发布。

当前状态：`Foundation / Contract Freeze`。
