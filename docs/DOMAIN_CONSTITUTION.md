# Domain Constitution

以下规则不可破坏：

1. 用户先分析，GPT 后点评。
2. Initial Analysis 一旦提交不得覆盖。
3. 评价分析过程，不根据后来行情结果倒推对错。
4. 当前 Stage 决定知识边界。
5. 只有 `CORE` 且当前 Stage `Allowed` 的知识可以作为正式判错依据。
6. GPT 不得主动无限扩展知识。
7. 重复错误优先通过训练解决，不优先增加知识。
8. 知识只补当前训练闭环真正缺少的最小部分。
9. Evaluation 低置信或信息不足时必须允许 Abstain。
10. Review 用于验证错误是否真正改善。
11. 一次 Training 只设一个主要训练目标。
12. 不建立自己的完整技术分析知识库。
13. 第一版遵循 YAGNI：没有当前明确需求，不开发。
14. Public 仓库不得保存用户私人训练数据。
15. 学习插件只供私人使用，默认禁止公开发布。
